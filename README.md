## 🚀 Featured Project

### ⚡ Monitoring and Analysis of Grid Frequency

A project focused on monitoring and analyzing electrical grid frequency using an embedded measurement system.

**Key components:**

* Voltage sensing using **ZMPT101B**
* Signal conditioning and noise filtering
* Zero-crossing based frequency measurement
* Real-time frequency monitoring
* Historical frequency-data collection
* Machine-learning-based frequency prediction

The project explored how measured grid-frequency patterns can be used to identify and predict short-term frequency behavior.

🏆 **Recognized as a winning project/team at Kathmandu University** and presented at **KUCAP**.

## 🔌 Current Research Direction

### Machine Learning for DC Fault Detection in VSC-MTDC Systems

I am currently exploring the application of **machine learning to fault analysis in VSC-based multi-terminal HVDC systems**.

My work involves:

`PSCAD Simulation → Fault Generation → Data Extraction → Feature Engineering → ML Model → Fault Classification`

The study focuses on disturbances such as:

* Pole-to-pole faults
* Pole-to-ground faults
* Transient behavior of VSC-MTDC networks
* Extracting simulation data for machine-learning applications
* Developing data-driven approaches for faster fault identification
